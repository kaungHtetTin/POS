# Compact login

Login opts into a compact authentication layout: 336px form width, smaller heading, reduced field gaps and compact remember-me row and submit button. Other authentication screens retain their existing sizing. Mobile cashier sign-in uses reduced card padding and heading spacing while retaining 44px input/button touch targets.

Browser checks: desktop, short desktop, mobile portrait and landscape fit; local invalid credentials feedback; successful sign-in; mobile cashier login rendering. Frontend-only release.
