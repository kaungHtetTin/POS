# App bar styling

The shared app bar retains its compact 48px height with a subtle theme-tinted
background, soft shadow and accent line. Current-section icon and stacked labels
make the active workspace easier to recognize. Language, theme and refresh
utilities share a bordered control group, and desktop users have a profile shortcut.
The existing POS branch switcher uses a tinted surface and decorative chevron.
Page-specific controls remain in the existing scrollable action portal.

Desktop, dark and mobile layouts are checked alongside profile navigation,
page action availability, theme switching, refresh, language selection and branch
menu operation. Mobile utilities retain 40px touch targets. The update changes
frontend presentation only and preserves account and business data.
