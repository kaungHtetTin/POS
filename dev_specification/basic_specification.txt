Pharmacy POS System
Complete Software Requirement Specification (SRS)
1. System Overview

The Pharmacy POS System is designed to manage medicine sales, inventory, purchases, financial records, expiration tracking, and multi-branch operations for pharmacy businesses.

The system must support:

Medicine sales using barcode scanning

Inventory tracking with batch and expiry management

Financial management and reporting

Multi-unit medicine sales (box, pack, tablet)

Multi-branch store management

Role-based access control

The system should integrate with hardware devices such as:

Barcode scanners

Barcode printers

Receipt printers

2. User Roles & Access Control

The system must support Role-Based Access Control (RBAC).

2.1 Owner / Admin

Full access to the system.

Permissions:

Manage system settings

Manage users

Manage branches

View all reports

Access financial reports

2.2 Manager

Permissions:

Manage inventory

Manage purchases

Manage suppliers

View sales reports

Monitor staff activity

2.3 Sales Staff (Cashier)

Permissions:

Process sales transactions

Scan products

Print receipts

Handle returns

View limited sales information

3. POS Sales Module
Core Features

Fast POS interface

Add items to cart

Supported Payment Types

Cash

Credit / Debit card

Mobile payment

Digital wallet

4. Medicine Unit Conversion System

Pharmacies sell medicines in multiple unit levels.

Example structure:

1 Box = 10 Cards
1 Card = 10 Tablets

The POS must support selling by:

Box

Bottle

Pack / Card

Single tablet

The system must automatically convert and update inventory.

Example:

Stock = 1 box (100 tablets)

Selling 3 tablets → stock becomes 97 tablets.

Each stock entry must include:

Batch number

Expiry date

Purchase date

Supplier information

FEFO (First Expire First Out)

The POS must automatically sell medicine with the earliest expiry date first.

Expiry Alerts

90 days before expiry

60 days before expiry

30 days before expiry

Example:

System suggests:

This helps avoid lost sales.
