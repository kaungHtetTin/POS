# POS workspace refresh

Refined catalog and current-sale panels with compact spacing, rounded borders and a neutral order header. Search and category fields have consistent sizing; list/grid controls have accessible names. Product cards use consistent borders and hover states. The total is more prominent and the primary checkout/shift action has a larger target. Dark mode uses a lighter total color for contrast.

Existing barcode search, pricing modes, cart calculations, shift requirements, checkout and mobile steps are retained. Browser checks cover view switching, local synthetic cart edits and totals, dark mode, viewport fit and mobile cart navigation. Live checks avoid creating sales or shifts.
